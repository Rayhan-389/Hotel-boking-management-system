# Hotel Booking Data Analysis

## 📌 Project Overview
This project focuses on analyzing hotel booking data to discover customer behavior, reservation trends, cancellation patterns, and booking preferences. The analysis was performed using Python in a Jupyter Notebook environment using data analysis and visualization libraries.

The main goal of this project is to identify useful business insights from hotel booking datasets.

---

# 📊 Objectives

- Analyze hotel booking trends
- Identify cancellation patterns
- Compare different hotel types
- Analyze customer reservation behavior
- Visualize booking statistics and trends

---

# 📂 Dataset Features

The dataset contains:

- Hotel Type

- Cancellation Information
- Monthly & Yearly Trends
